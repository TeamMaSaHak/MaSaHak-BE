# 마법사관학교 앱 프로젝트 배경

## 프로젝트 개요

디스코드 스터디 서버 **"마법사관학교"**와 연동되는 모바일 앱 개발 프로젝트입니다.

---

## 기존 시스템

### 디스코드 스터디 서버
- **서버명**: 마법사관학교
- **목적**: 공부 시간 트래킹 및 스터디 커뮤니티 운영
- **특징**: 기숙사 역할(Role) 시스템 운영

### 기존 디스코드 봇 (profile_bot)
디스코드 서버에서 운영 중인 봇으로, 다음 기능을 제공합니다:

| 테이블 | 설명 |
|--------|------|
| `users` | 유저 정보 (레벨, XP, 학번, 닉네임 등) |
| `voice_sessions` | 음성 채널 공부 세션 기록 |
| `daily_streaks` | 일별 출석 기록 |

**핵심 기능**:
- 음성 채널 접속 시 공부 시간 자동 기록
- 레벨 시스템 (XP 기반)
- 학번 자동 부여 (가입일 기반)
- 출석 스트릭 관리

## 시스템 연동

### 공부 시간 통합
앱과 디스코드 봇의 공부 시간을 통합 관리합니다.

```
voice_sessions.source 컬럼으로 출처 구분:
- discord      : 디스코드 음성 채널
- app_timer    : 앱 타이머 모드
- app_pomodoro : 앱 뽀모도로 모드
```

### 인증 방식
- **마사학 유저**: 디스코드 OAuth 2.0
- **게스트**: 별도 인증 없이 로컬 데이터로 사용

### 푸시 알림
- Firebase Cloud Messaging (FCM) 사용
- 일기 답장 알림, 공지사항 등
