## 1. 사용자 인증

### 1.0 스플래시 스크린

#### 1.0.1 앱 초기화 및 인증 체크
- **도메인**: 사용자 인증
- **범위**: 🔴 게스트, 🔵 마사학 유저
- **설명**:
  - 앱 실행 시 스플래시 화면 표시 (1~2초)
  - 로컬 저장소에서 JWT 토큰 확인
  - Logic:
    - (토큰 없음): 로그인 화면(1.1)으로 이동
    - (토큰 있음): 서버에 토큰 유효성 검증 요청
      - (유효): 메인 화면(2.1)으로 이동
      - (만료): refresh token으로 갱신 시도
        - (성공): 메인 화면으로 이동
        - (실패): 로그인 화면으로 이동
- **참고사항**:
  - 토큰 검증은 인증 필요한 API 호출 시 JWT Guard가 자동 처리
  - 스플래시 로직은 프론트엔드에서 처리, 백엔드는 `/api/auth/refresh` API 제공

### 2.3 뽀모도로 기능 (count-down)

#### 2.3.1 뽀모도로 설정 UI
- **범위**: 🔴 게스트, 🔵 마사학 유저
- **설명**:
  - **Location**: 캐릭터 이미지 하단에 설정 컨트롤러 노출
  - **Items**:
    - ① **집중 시간**: - 숫자(분) + (단위: 5분 증감)
    - ② **쉬는 시간**: - 숫자(분) + (단위: 1분 증감)
    - ③ **반복**: - 숫자(회) + (단위: 1회 증감)
  - **Indicator**: 모드 전환 버튼 하단에 **[반복]** 횟수만큼 '빈 동그라미(○)' 생성
- **참고사항**: 빈 동그라미 생성 = 동적으로 생성한다.

#### 2.3.2 뽀모도로 실행 로직
- **설명**:
  - Action (재생): 재생 버튼 클릭 시
    - ① Display Update: 상단 시간을 설정된 [집중 시간]으로 즉시 변경 (예: 25분 설정 → 00:25:00)
    - ② Countdown: 1초 단위로 시간 차감 시작
    - ③ Button: 재생(▶) → 일시정지(❚❚) 변경
  - Cycle Logic: [집중 시간] 1세트 완료 시 (쉬는 시간 고려x) → 상단 인디케이터 동그라미 1개 채움(●)
- **참고사항**:
  - 반복이 5번이라면 집중시간 5번, 쉬는시간 4번 (추후 변경 할 수 있음)
  - 집중시간이 끝나면은 상단 인디케이터 동그라미 1개 채움(●)

#### 2.3.3 뽀모도로 리셋
- **설명**:
  - **Trigger**: 실행 중 또는 일시정지 상태에서 좌측 리셋(↺) 버튼 클릭
  - Action: 2.4 리셋 모달 호출

  - Indicator (Study Time): 각 날짜 셀 내부에 해당 날의 공부 시간 표시 (HH:MM 형식)
  - Indicator (Diary): 일기가 작성된 날짜에는 날짜 위에 '각 해당 기숙사색상 점' 표시 (마사학 유저만 해당)
- **참고사항**: 공부시간 저장하고 표시하는 건 게스트도 유지

---

### 4.3 통계 시스템

#### 4.3.1 하단 통계 패널
- **범위**: 🔵 마사학 유저
- **설명**:
  - [일별 통계] - 캘린더에서 특정 날짜를 클릭했을 때
    - Data Sources:
      - ① 오늘 공부한 시간
      - ② 어제 대비 오늘 공부 증감량
      - ③ 오늘 공부 시작 시간
      - ④ 가장 긴 집중 시간 (쉬는시간 포함)
  - [기본 통계] - 캘린더 들어갔을 때
    - Data Sources:
      - ① 이번달 출석 횟수 (N/M)
      - ② 이번달 총 집중 시간
      - ③ 이번달 일 평균 집중 시간 (출석한 날 기준)
      - ④ 완료한 투두 리스트
- **참고사항**:
  - 연별 공부량은 사용자가 2024년 캘린더를 보고 있다면 2024년 데이터, 2025년으로 이동하면 2025년 데이터로 동적으로 갱신되어야 함
  - 캘린더 들어갔을때는 오늘 날짜로 [일별 통계] [기본통계] 가 보인다.
  - 다른 날짜 들어가면 [기본통계는] 해당 월에 대한 데이터로 출력이 되고 / [일별 통계]는 해당하는 날에 대한 통계를 보여준다.

### 5.2 일기 작성 및 조회

#### 5.2.1 작성 모드 (Active)
- **범위**: 🔵 마사학 유저
- **설명**:
  - Condition: 당일 06:00 ~ 다음날 05:59 사이
  - UI: 공책(줄글) 디자인의 입력 영역
  - Action: 영역 클릭 시 텍스트 작성 및 수정 가능
  - Save: "저장"버튼을 눌러야지 실제 DB에 저장됨
    - 05:59분이 지나서 저장하기 버튼을 누르면 "작성시간이 지났습니다 ~~. 입력시간은 05:59분까지 입니다." 텍스트가 뜨는 모달창이 뜬다.
  - Constraint: 이전 날짜의 일기는 작성/수정 불가
- **참고사항**:
  - 일기 작성 마감(00:00)과 답장 노출(09:00)은 서버 시간(KST 한국 시간)을 기준으로 동작
  - 클라이언트(앱) 시간을 조작하여 05:59 이후에 수정하는 것을 막기 위해, 수정 요청 시 서버단에서도 시간 검증이 필요

#### 5.2.2 작성 마감 (Lock)
- **설명**:
  - Condition: 다음날 06:00 도달 시
  - Action:
    - ① 수정 불가: 입력 필드 Read-only 전환
    - ② UI 변경: 입력창 높이(Height)를 작성된 텍스트 길이에 맞춰 조절 (여백 제거)

---

### 5.3 LLM 답장 시스템

#### 5.3.1 답장 생성 (Background)
- **범위**: 🔵 마사학 유저
- **설명**:
  - Trigger: 매일 06:05 (작성 마감 5분 후)
  - Logic:
    - ① 전날 작성된 일기 데이터 수집
    - ② LLM 모델을 통해 답장 생성 및 DB 저장 (사용자에게 노출 X)
  - Exception: 내용이 없거나(Empty), 작성 후 모두 지운 경우 답장 생성 X
- **참고사항**:
  - 백에서 api 09:00에 클라로 쏘기로
  - 이 알람 기능은 일기를 쓴사람의 한해서 무조건 알람 보냄 (오류났는지 모름)

#### 5.3.2 답장 노출 (Display)
- **설명**:
  - Trigger: 매일 09:00 (오전 9시)
  - UI: 사용자가 쓴 일기 하단에 답장 영역 추가
  - Style: 어두운 회색 배경 + 흰색 텍스트 (사용자 일기와 시각적 구분)
  - Content: 5.3.1에서 생성해둔 LLM 답장 내용 표시

## 7. 알림

### 7.1 알림 진입 (Entry)

#### 7.1.1 메인 알림 아이콘
- **도메인**: 알림
- **범위**: 🔴 게스트, 🔵 마사학 유저
- **설명**:
  - UI: 홈/캘린더 등 메인 화면 우측 상단 '편지(✉️) 아이콘' 배치
  - Badge Logic (Global):
    - ① (안 읽은 알림 O): 아이콘 우측 상단에 '작은 점(Dot)' 표시
    - ② (모두 읽음): 점 미표시 (아이콘만 노출)
  - Action: 아이콘 클릭 시 7.2 알림 목록 페이지로 이동

---

### 7.2 알림 목록 (List)

#### 7.2.1 알림 리스트 UI
- **설명**:
  - Header: 뒤로가기 버튼(<), 타이틀("알림")
  - Body: 수신된 알림 카드 리스트 (최신순 정렬)
  - Content Example:
    - ① 업데이트 공지
    - ② 09:00에 일기 쓴사람 일괄 알림 보내기(push알람)
- **참고사항**:
  - 현재 알림 기능은 최소한으로 업데이트 공지 및 서버내에서 공지하는 걸로 한정하도록 함.
  - 정렬: 통상적으로 최신 알림이 최상단에 오도록 내림차순 정렬을 기본

#### 7.2.2 읽음 상태 표시 (Dot)
- **설명**:
  - Logic: 개별 알림의 읽음(Read) 여부에 따라 상태 구분
  - UI:
    - ① (안 읽음): 카드 우측 중앙에 '점(Dot)' 표시
    - ② (읽음): 점 표시 없음

---

### 7.3 알림 상태 관리

#### 7.3.1 읽음 처리 (Action)
- **설명**:
  - Trigger: 리스트 내 특정 알림 카드 클릭
  - Action:
    - ① 해당 알림의 상세 페이지 이동 (또는 단순 확인)
    - ② 즉시 DB 상태 변경 (Unread → Read)
    - ③ 우측 점(Dot) 제거 및 메인 아이콘 배지 카운트 갱신
- **참고사항**: 상태 동기화 (State Sync): 알림 목록에서 특정 알림을 클릭하여 '읽음' 처리가 되면, 다시 메인 화면으로 나갔을 때 편지 아이콘의 점(Badge) 상태도 즉시 갱신 (예: 1개 남은 안 읽은 알림을 읽고 나가면, 밖에서도 점이 사라져야 함)
