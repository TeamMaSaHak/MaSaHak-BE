## 게스트 vs 마사학 유저 권한 정리

> 명세서 부록 기반 - 게스트 접근 시 UI 처리 참고

| 기능 | 게스트 | 마사학 유저 | 게스트 UI 처리 |
|------|:------:|:----------:|---------------|
| 타이머 | ✅ | ✅ | 동일 |
| 뽀모도로 | ✅ | ✅ | 동일 |
| 투두리스트 | ✅ | ✅ | 동일 (로컬 저장) |
| 캘린더 (기본) | ✅ | ✅ | 동일 |
| **캘린더 통계** | ❌ | ✅ | **블러 + 오버레이 텍스트** |
| **일기 작성/조회** | ❌ | ✅ | **블러 + 오버레이 텍스트** |
| **LLM 답장** | ❌ | ✅ | - |
| **학생증** | ⚠️ | ✅ | **게스트용 고정 데이터 표시** |
| 허용 어플 관리 | ✅ | ✅ | 동일 (로컬 저장) |
| 알림 | ✅ | ✅ | 동일 |
